# WelfareHub

WelfareHub is an admin-based Laravel CRUD application developed to manage welfare society activities.

## Features

- Member Management
- Fee Record Management
- Meeting Management
- Announcements
- SMS Meeting Reminders using Text.lk
- Active / Inactive Member Management
- Admin Dashboard

## Technologies Used

- Laravel
- PHP
- MySQL
- Tailwind CSS
- JavaScript
- Blade
- Text.lk SMS API
